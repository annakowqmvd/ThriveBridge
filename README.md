# ThriveBridge

ThriveBridge enables real-time, high-performance data exchange between decentralized networks through a dynamically scalable gateway.

With ThriveBridge, you get a lightweight tool that stays out of your way.

**What you get**

- ThriveBridge enables real-time, high-performance data
- exchange between decentralized networks through
- a dynamically scalable gateway

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/ThriveBridge.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure ThriveBridge, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
